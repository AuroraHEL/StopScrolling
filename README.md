# 📵 Stop Scrolling

> An Android application built with Kotlin designed to counter compulsive smartphone usage by locking the screen after a set limit and requiring users to complete real-world challenges to unlock it.

* **Course:** Mobile Application Development Project (TX00EY39-3007)

## 🎯 Features & Challenges

**Stop Scrolling** tracks screen usage and interrupts prolonged scrolling sessions. To regain access to the phone, users must complete a randomized or selected challenge:

* 📸 **Camera Task:** Take a photo of a specific object or environment using the CameraX API.
* 📶 **Peer-to-Peer Unlock (Bluetooth):** Ask a nearby friend to authorize unlocking via Bluetooth communication.
* 🧠 **Mental Challenges:** Solve a math quiz or explore a new educational topic.
* 🏃 **Physical Activity:** Complete a movement session (e.g., 10 minutes of walking/steps tracked via internal device sensors).
